# My Website Project

## About

This is a simple website I created using HTML. I worked on this project to practice Git branching, merging, and resolving conflicts.

## Features

- Navigation bar with Home, About, and Contact links
- Hero section with an image and description
- Contact form with name, email, and message fields
- Customer testimonials
- Footer

## Technologies Used

- HTML
- Git
- GitHub
- Visual Studio Code

## What I Learned

In this project, I learned how to create branches, make changes, commit my work, merge branches, and resolve merge conflicts using Git.

## How to Run

Open the `index.html` file in any web browser.
